# Slow Glow — демонстрационный сайт

Одностраничный адаптивный сайт студии Slow Glow (Королёв, проспект Космонавтов, 34Б). Без базы данных, админ-панели и бэкенда.

## Запуск

Откройте `index.html` в браузере или опубликуйте содержимое папки на статическом хостинге (например, GitHub Pages).

## Источники сведений

Открытая карточка студии: https://yandex.ru/maps/org/slow_glow/66417508852/

Подтверждённые услуги: маникюр с покрытием гелем — 2800 ₽; педикюр с покрытием — 3000 ₽; архитектура бровей — 1900 ₽; коррекция наращивания — 3000 ₽. Телефон +7 (995) 897-38-41.

Ссылка «Записаться онлайн» ведёт на карточку Яндекс Карт с действующим сервисом онлайн-записи, а не на имитацию формы.

## Что нужно согласовать до официальной публикации

- Получить разрешение владельца на использование логотипа и фотографий из карточки/отзывов на Яндекс Картах; при необходимости заменить собственными материалами студии.
- Главное фото маникюра — иллюстративное изображение с Unsplash, не портфолио Slow Glow. Лучше заменить на фирменную фотосессию или работу мастера.
- Сверить цены и актуальные часы работы, а также проверить маршрут записи с владельцем.
- Подтвердить возможность покупки сертификата; по карточке Яндекс Карт есть отметка о подарочных сертификатах.
- Настроить домен, аналитику и SEO после одобрения дизайна.

## Технические решения

- Чистый HTML / CSS / JavaScript в одном файле.
- Фотографии по внешним URL (для полноценного автономного размещения их нужно сохранить с разрешения правообладателя).
- Иконки — SVG, без системных эмодзи.
- Адаптивная верстка, мобильное меню, фильтры услуг, полноэкранная галерея, ссылки на звонок, онлайн-запись и маршрут.
